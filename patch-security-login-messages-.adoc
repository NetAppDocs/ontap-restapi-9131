= Update a TOTP profile for a user account

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/security/login/totps/{owner.uuid}/{account.name}`#

*Introduced In:* 9.13

Updates a TOTP user account.

== Related ONTAP commands

* `security login totp modify`

== Learn more

* link:manage_totp_profile_for_a_specific_user_account.html[DOC /security/login/totps/{owner.uuid}/{account.name}]
* link:manage_security-related_accounts.html[DOC /security/accounts]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|owner.uuid
|string
|path
|True
a|Account owner UUID


|account.name
|string
|path
|True
a|User account name

|===

== Request Body

                

[cols=3*,options=header]
|===
|Name
|Type
|Description

|comment
|string
a|Optional comment for the TOTP profile.


|enabled
|boolean
a|Status of the TOTP profile.


|scope
|string
a|Scope of the entity. Set to "cluster" for cluster owned objects and to "svm" for SVM owned objects.


|sha_fingerprint
|string
a|SHA fingerprint for the TOTP secret key.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "comment": "string",
  "enabled": "",
  "scope": "string",
  "sha_fingerprint": "string"
}
====

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 144834564
| Only users with the admin role are allowed to modify the TOTP status.

| 144834565
| Invalid option for the field -enabled

| 144834566
| TOTP is not configured for the user
|===
