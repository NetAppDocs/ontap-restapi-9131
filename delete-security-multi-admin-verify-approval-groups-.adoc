= Delete a multi-admin-verify approval group
:imagesdir: ./media/

[.lead]
Deletes a multi-admin-verify approval group to remove the group's authorization structure. This action is typically used when you need to change or consolidate approval groups.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/security/multi-admin-verify/approval-groups/{owner.uuid}/{name}`#

ONTAP 9.11
