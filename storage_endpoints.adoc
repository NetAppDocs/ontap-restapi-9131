= ONTAP REST API storage endpoints
:imagesdir: ./media/

[.lead]
Manage physical and logical storage using ONTAP storage APIs, which handle aggregates, volumes, LUNs, qtrees, snapshots, quotas, and storage efficiency. These endpoints are essential for effective capacity allocation and protection in your environment.

== Overview

The ONTAP storage APIs can be used to manage physical and logical storage. This includes management of aggregates, volumes, LUNs, qtrees, snapshots, quotas, and storage efficiency.
