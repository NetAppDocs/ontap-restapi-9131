= Update a multi-admin-verify approval group
:imagesdir: ./media/

[.lead]
Updates the configuration of a multi-admin-verify approval group, managing its settings to ensure proper administrative action approvals.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/security/multi-admin-verify/approval-groups/{owner.uuid}/{name}`#

== Introduced in

ONTAP 9.11

== Usage notes

Updates a multi-admin-verify approval group.

|===

|Type
|Description

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 262331
| At least one approver is required.

| 262332
| An add or remove list is required.
|===
